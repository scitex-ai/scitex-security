# scitex-security runtime

This directory holds **regenerable data** — alert report files, symlinks,
and other outputs that are automatically produced by `scitex-security`
and can be re-created from configuration + source.

Contents are **not committed** to git (only this `README.md` and
`.gitkeep` are tracked). See the [local-state-directories
skill](/home/ywatanabe/proj/scitex-dev/src/scitex_dev/_skills/general/01_ecosystem/06_local-state-directories.md)
for the canonical layout rules.
