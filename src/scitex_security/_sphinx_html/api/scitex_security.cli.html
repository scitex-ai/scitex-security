scitex_security.cli

CLI for scitex-security — GitHub security-alert utilities.

Subcommands follow the verb-noun convention (general/03_interface_02_cli):

scitex-security check [REPO] # Check Dependabot/CodeQL alerts scitex-security show-latest # Print latest saved report scitex-security list-python-apis # Introspect public Python API scitex-security mcp list-tools # Introspect MCP tool surface (none)
